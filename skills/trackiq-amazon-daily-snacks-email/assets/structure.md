# Structure

Order is fixed. It moves from story to numbers to actions, so a reader who
stops halfway still leaves with the argument.

| Section | Job |
|---|---|
| **Masthead** | Logo + "Snacks" in sand, 4px sand rule under the sage bar |
| **Hey Sellers** | Date/brand eyebrow, greeting, the cold open, then the headline numbers in one sentence |
| **The numbers** | 2×2 big KPI cards: retail + ad spend for the settled day, then the same pair for the week. TACoS and ROAS ride in the week card's supporting line |
| **The Big Bite** | The one story. Kicker, 31px headline, two paragraphs, one chart |
| **The Takeaway** | Sage panel. The verdict, and where the money actually is. No new numbers |
| **Quick Bites** | Four color-railed cards, one number and one implication each |
| **The Scoreboard** | Three equal tiles: best line, worst line, biggest leak |
| **Every line, ranked** | One card per product line, biggest retail first. Retail + delta on the head row, spend and TACoS below, a plain-English verdict last |
| **The trend** | Seven daily bars, then this-week vs last-week |
| **Three charts** | Revenue mix, TACoS by line, DSP return by campaign — each with a caption that says what it means |
| **On the shelf** | Three-tile rank summary, then one card per hero: rank, BSR movement, badge state, head term and tracked-term count |
| **What else we're snacking on** | Four bulleted loose ends |
| **Snack Fact of the Day** | Dashed sand box. A business insight with a dollar figure as the hero — never trivia |
| **On today's menu** | Numbered actions, colored by type: red = cut, green = fund, mocha = admin |
| **Footer** | Sage. Logo, account line. Nothing else — this is internal |

## The Snack Fact

The most-read box in the email, so it does real work. It reframes the
week's data as one number nobody computed: an efficiency gap annualised, a
cost of inaction, an opportunity sized. Structure is a 30px hero figure,
then the arithmetic in plain language. Never a fun fact, never a
factoid about the category or Amazon trivia.

## Section headings

24px/700 sentence-case title, then a 13px muted one-line subhead that sets
up what follows. No numerals, no uppercase eyebrows on the big sections —
those belong to the panels inside them.
